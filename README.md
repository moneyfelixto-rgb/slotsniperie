# Slotsniperie

> Project Name: Driving Slot Sniper (Ireland) — WhatsApp First Platform
> System Architecture & Task Description:
> Build a minimalist, high-converting, luxury-dark-themed landing page and payment portal for an automated Irish Driving Test booking service.
> Crucial architecture note: There is NO heavy web dashboard. The entire user journey (onboarding, preference selection, and real-time alerts) happens exclusively through a WhatsApp Bot.
> The web app has only two lightweight functions:
>  * The Landing Page: A high-impact hero section driving users directly into the WhatsApp automated workflow.
>  * The Express Payment Portal: A simple, secure mobile-first checkout page linked via a short URL generated by the WhatsApp bot strictly AFTER a test slot has been successfully booked.
> Key Features & UI Sections:
>  * Hero Landing Section (Mobile-First):
>  * Headline: "Get Your Irish Driving Test Next Week. Pay Only When Booked."
>  * Subheadline: "Zero apps to download. Zero upfront fees. Free real-time slot alerts via WhatsApp. Pay €60 only after our bot successfully secures your test slot."
>  * Primary CTA Button: "Start Free via WhatsApp" (Direct link opening WhatsApp chat with pre-filled automated text: "Hi, I want to find a driving test slot in Dublin").
>  * Trust Badges: "Pay-On-Success", "RSA Compliant Flow", "100% Secured".
>  * Express Payment Portal (Short-URL Route e.g., /pay/[id]):
>  * Clean, minimalist checkout interface triggered only upon successful slot acquisition.
>  * Dynamic Booking Summary Card: Displays Test Center name (e.g., Finglas, Tallaght), Date, Time, and Driver/Reference details.
>  * Payment Integration: Revolut Pay & Stripe integration buttons for a fixed €60 service fee.
>  * Urgency Timer: A visual countdown timer (e.g., "Slot held for 01:59:00 before auto-release").
>  * Success State: Instant confirmation screen with download/receipt and instructions to check official RSA email.
> Design System & Aesthetics:
>  * Theme: Premium Dark Mode (Obsidian black background #0A0A0A, sleek neon green accent #00FF66, high contrast typography).
>  * Style: Brutalist minimalism, sharp edges, zero clutter, lightning-fast load time.
>  * Responsive: Optimized strictly for mobile screens, as 95% of users will open it via WhatsApp links on their phones.
> Generate the landing page structure, the routing for the express checkout page, and smooth interactive states.
